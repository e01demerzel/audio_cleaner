# Чистый голос

Приложение для Windows 10/11: уменьшает постоянный фоновый шум диктофонных записей (шипение, гул, шум вентилятора), повышает разборчивость речи и выравнивает громкость. Все вычисления локальные, запись никуда не отправляется. Интернет нужен только для установки.

## Запуск на Windows

1. Установите **64-разрядный Python 3.10 или новее** с python.org с компонентами **Python Launcher** и **Tcl/Tk** (обычно включены).
2. Скачайте файлы проекта в одну папку. Дважды нажмите `install_windows.bat` и дождитесь завершения установки.
3. Запустите `start_windows.bat`.
4. Выберите запись и путь результата. Начните с силы очистки **60%**, оставьте усиление голоса включённым и нажмите «Очистить запись».
5. Нажмите «Прослушать результат»: откроется стандартный проигрыватель Windows. Для сравнения откройте оригинал в проигрывателе.

Поддерживаются распространённые входные форматы, включая WAV, MP3, M4A, AAC, FLAC, OGG, WMA и аудиодорожку MP4. Выход: WAV, FLAC или MP3. WAV/FLAC предпочтительны для дальнейшего монтажа. Результат имеет частоту 48 кГц; исходное число каналов сохраняется. Для контейнеров с несколькими аудиодорожками используется первая.

Исходная запись не изменяется. Существующий результат заменяется только после успешной обработки; интерфейс запрашивает подтверждение. Можно отменить обработку. Длинные записи обрабатываются потоково без загрузки целиком в память; на диске нужно место для результата.

## Отдельный EXE

После установки запустите `build_windows.bat` **на Windows**. Готовый файл: `dist\AudioCleaner.exe`. В него включается FFmpeg; Python на другом компьютере не потребуется. Сборка Windows EXE на Linux не поддерживается. Неподписанный EXE может вызвать предупреждение SmartScreen; при распространении проверьте лицензии FFmpeg и используемых компонентов (см. `imageio_ffmpeg/binaries/README.md` установленного пакета).

## Возможности и ограничения

Используются FFmpeg: срез низкочастотного гула, спектральное подавление шума, небольшое усиление области разборчивости, компрессия и нормализация к −16 LUFS с ограничением пиков. Это обычная обработка сигнала, без нейросети и без загрузки моделей.

Полностью убрать любые шумы нельзя. Чужая речь, музыка, удары, ветер и сильное эхо могут остаться. Перегруженную или отсутствующую речь восстановить нельзя. Сильная очистка может придать голосу металлический оттенок: уменьшите ползунок. При 0% отключается спектральное шумоподавление, но остаётся срез низких частот. Для чистого, но тихого оригинала попробуйте 0–20%. Усиление повышает также остаточный шум; его можно отключить.

## Командная строка и разработка

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python audio_cleaner.py "original.m4a" "clean.wav" --strength 60
python -m unittest discover -s tests -v
```

Без аргументов запускается графический интерфейс (нужен Tkinter). CLI заменяет указанный файл результата без запроса. При совпадении путей входа и выхода операция отклоняется. FFmpeg берётся из пакета imageio-ffmpeg; если пакет не установлен, используется системный FFmpeg.
