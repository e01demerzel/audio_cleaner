# Чистый голос 2 — нейросетевая очистка диктофонных записей

Приложение для **Windows 10/11, 64 бит**: подавляет фоновый шум и выравнивает громкость голоса. Основной режим использует **DPDFNet, нейросетевую модель речи с выходом 48 кГц**, через sherpa-onnx. Видеокарта не нужна. Аудиозаписи не покидают компьютер; Интернет нужен при установке зависимостей и модели (~10 МБ), после этого обработка работает офлайн.

## Обновление с первой версии

1. [Скачайте актуальный ZIP](https://github.com/e01demerzel/audio_cleaner/archive/refs/heads/main.zip) и распакуйте **в новую папку**.
2. Запустите `install_windows.bat`. Не пропускайте этот шаг: появились новые зависимости и нейросетевая модель.
3. После успешной установки запустите `start_windows.bat`.
4. Выберите **«AI — глубокая очистка речи»**, силу **100%**, включите «Подавлять остаточный фон в паузах» и обработайте **оригинальную запись**, а не результат старой версии.

Проверьте на фрагменте речи, не исчезают ли тихие слова. Если голос искажается, уменьшите силу до 80–90%. При этом возвращается часть оригинала, включая его шум. При обрезании тихих окончаний выключите подавление фона в паузах. Старый алгоритм доступен в режиме «Быстрая очистка».

## Первая установка на Windows

1. Установите **64-разрядный Python 3.12** с python.org с компонентами **Python Launcher** и **Tcl/Tk** (обычно включены). Исходный код рассчитан на Python 3.10+; установка и сборка рекомендуются с 3.12.
2. Скачайте ZIP репозитория, распакуйте и дважды нажмите `install_windows.bat`.
3. Запустите `start_windows.bat`, выберите запись и путь результата, нажмите «Очистить запись».
4. Кнопка «Прослушать результат» открывает стандартный проигрыватель Windows. Для сравнения откройте исходник в проигрывателе.

Установка может занять несколько минут. Если загрузка модели с GitHub недоступна, установка покажет ошибку. Повторите её при рабочем соединении. Программа **не переключается незаметно на прежнее шумоподавление**, если AI-модель отсутствует или повреждена: появится понятное сообщение. Быстрый режим можно выбрать вручную.

## Обработка и форматы

- Вход: WAV, MP3, M4A, AAC, FLAC, OGG, WMA и аудиодорожка MP4; используется первая аудиодорожка.
- Выход: WAV, FLAC или MP3, 48 кГц. Для монтажа предпочтительны WAV/FLAC.
- **AI переводит запись в моно**, что подходит для диктофона/одного голоса. Быстрый режим сохраняет число каналов. Стереозапись не обрабатывается нейросетью по каналам раздельно.
- Предварительное выравнивание очень тихого входа для нейросети → нейросетевая очистка с восстановлением исходного уровня → срез низкочастотного гула → опциональное мягкое подавление остаточного фона в паузах с порогом, зависящим от уровня записи → обработка разборчивости и громкости.
- Громкость измеряется отдельно. Затем применяется постоянное усиление с целью −16 LUFS и запасом по пикам −1,5 dBTP (до кодирования MP3), без отдельного подъёма шума в паузах. Усиление ограничено 40 дБ, при нехватке запаса по пикам итог может быть тише цели. Кодирование MP3 может немного изменить пики.
- При 0% нейросеть/спектральное шумоподавление и подавление фона в паузах отключаются; срез гула остаётся. Отключение «Усилить голос» также отключает эквалайзер, компрессию и нормализацию.

Исходник не изменяется. Результат заменяется только после успешной обработки; интерфейс запрашивает подтверждение перезаписи. Обработку можно отменить. Состояние нейросети сохраняется между блоками; задержка модели компенсируется, длительность и конец записи сохраняются. Длинные записи обрабатываются блоками; для временных файлов AI нужно **около 1,4 ГБ на час записи плюс место под результат** на диске назначения. Скорость зависит от процессора.

## Качество и сравнение с Auphonic

Первая версия использовала только обычное спектральное шумоподавление. Теперь модель отделяет речь от фона по обученным признакам, а усиление не поднимает тихие участки отдельно. Это более подходящий подход для сложного шума.

**Это не Auphonic и не гарантия идентичного звучания.** Здесь не используются их закрытые алгоритмы; сравнение на записи пользователя пока не выполнено. Чужая речь, музыка, ветер, сильная реверберация и перегрузка микрофона остаются сложными случаями. Модель может удалить тихую речь или исказить тембр. Программа предназначена для речи, а не для сохранения музыки/звуковой атмосферы. Полностью восстановить отсутствующий голос нельзя.

Автоматическая проверка использует реальную речь с добавленным меняющимся шумом и гулом. Она оценивает сохранение голоса относительно чистого эталона, остаточный фон в паузах, синхронизацию и длительность. Это воспроизводимая инженерная проверка, а не оценка качества всех диктофонных записей.

## Отдельный EXE

После установки запустите `build_windows.bat` **на 64-разрядной Windows с Python 3.12**. Получится `dist\AudioCleaner.exe` с FFmpeg, CPU-движком и моделью внутри. На другом компьютере Python и загрузка модели не потребуются. Сборка/запуск Windows EXE в текущей Linux-среде не проверялись. Неподписанный EXE может вызвать предупреждение SmartScreen.

Лицензии используемых компонентов: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Командная строка и разработка

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python audio_cleaner.py --download-model --model-dir models
python audio_cleaner.py "original.m4a" "clean.wav"
python audio_cleaner.py "original.m4a" "fast.wav" --engine fast --strength 60
python -m unittest discover -s tests -v
```

Без аргументов запускается графический интерфейс (нужен Tkinter). CLI заменяет файл результата без запроса; совпадение путей входа и выхода запрещено. Ключи: `--strength 0..100`, `--no-enhance`, `--keep-pauses`, `--engine neural|fast`, `--model-dir PATH`, `--download-model`.

По умолчанию модель хранится в `%LOCALAPPDATA%\AudioCleaner\models` (на Linux/macOS — `~/.cache/AudioCleaner/models`). Приоритет: `--model-dir` → переменная `AUDIO_CLEANER_MODELS` → модель в папке `models` рядом с исходниками/внутри EXE → пользовательский кеш. Контрольная сумма SHA-256 проверяется перед загрузкой в движок. Если модель повреждена, повторная установка скачивает и атомарно заменяет её только после проверки. FFmpeg включён в пакет imageio-ffmpeg; системный используется, если пакет не установлен.
