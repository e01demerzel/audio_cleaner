# Чистый голос

Локальное приложение для Windows: уменьшает фоновый шум диктофонных записей, повышает разборчивость речи и выравнивает громкость. Результат по умолчанию сохраняется в **MP3, 192 кбит/с, 48 кГц**.

Нейросетевая очистка работает на процессоре, без видеокарты. Аудиозаписи обрабатываются на вашем компьютере. Интернет нужен для установки зависимостей и загрузки модели размером около 10 МБ; дальнейшая обработка работает офлайн.

## Возможности

- Нейросетевая очистка речи и быстрый режим для простого фонового шума.
- Настройка силы очистки и подавление остаточного фона в паузах.
- Усиление тихого голоса и выравнивание громкости.
- Выбор MP3, WAV, FLAC или AAC в главном окне и открытие результата в стандартном проигрывателе Windows.
- Отмена обработки и защита исходной записи от перезаписи.

## Установка на Windows

1. Установите **64-разрядный Python 3.12** с [python.org](https://www.python.org/downloads/windows/) с компонентами **Python Launcher** и **Tcl/Tk** (обычно включены).
2. [Скачайте ZIP проекта](https://github.com/e01demerzel/audio_cleaner/archive/refs/heads/main.zip) и распакуйте его.
3. Запустите `install_windows.bat`. Дождитесь установки зависимостей и загрузки модели.
4. Запустите `start_windows.bat`.

Поддерживаются Windows 10/11, 64 бит. Для обновления распакуйте свежую версию в новую папку и снова запустите `install_windows.bat`.

Если установка модели не завершилась, проверьте доступ к GitHub и повторите установку. Отсутствующая или повреждённая модель вызывает сообщение об ошибке. Для работы без модели можно вручную выбрать быстрый режим.

## Как очистить запись

1. Выберите исходную запись. Программа предложит сохранить результат рядом с ней как `имя_очищено.mp3`.
2. В списке **«Формат результата»** выберите **MP3**, **WAV**, **FLAC** или **AAC**. Расширение файла изменится автоматически. По умолчанию выбран MP3.
3. Оставьте режим **«AI — глубокая очистка речи»**, силу **100%**, усиление голоса и подавление фона в паузах.
4. Нажмите **«Очистить запись»**.
5. Нажмите **«Прослушать результат»**, чтобы открыть готовый файл в проигрывателе.

Начинайте с оригинальной записи. Если голос искажается, уменьшите силу до 80–90%: это возвращает часть исходного звука вместе с его фоном. Если пропадают тихие окончания слов, отключите подавление фона в паузах.

Исходник сохраняется без изменений. Если файл результата уже существует, интерфейс запросит подтверждение; замена выполняется только после успешной обработки.

## Форматы и качество

| Параметр | Поддержка |
| --- | --- |
| Вход | WAV, MP3, M4A, AAC, FLAC, OGG, WMA, аудиодорожка MP4 |
| Выход по умолчанию | MP3, 192 кбит/с, 48 кГц |
| Выбор в главном окне | MP3, WAV (PCM 16 бит), FLAC, AAC (192 кбит/с, файл `.aac`) |
| Каналы | AI сохраняет моно; быстрый режим сохраняет число каналов |
| Несколько аудиодорожек | Обрабатывается первая дорожка |

Приложение предназначено для речи. Музыка, чужие голоса, ветер, сильное эхо и перегрузка микрофона могут влиять на результат. При сильной очистке возможны изменения тембра или потеря тихой речи. Качество зависит от исходной записи.

WAV и FLAC сохраняют результат без дополнительного сжатия с потерями. MP3 и AAC создают более компактные файлы. Все варианты имеют частоту 48 кГц. AAC сохраняется в контейнере ADTS; из-за особенностей кодека при воспроизведении возможна небольшая добавка тишины в начале/конце.

Длинные записи обрабатываются блоками. Для временных файлов AI требуется около **1,4 ГБ на час записи плюс место под результат** на диске назначения. Скорость зависит от процессора.

## Сборка отдельного EXE

После установки запустите `build_windows.bat` на 64-разрядной Windows с Python 3.12. Готовый файл появится в `dist\AudioCleaner.exe`. Он содержит FFmpeg, движок и модель; для запуска на другом компьютере Python и загрузка модели не требуются.

Сборка выполняется на Windows; Windows EXE не проверялся в среде Linux. Лицензии компонентов перечислены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Командная строка и разработка

Исходный код рассчитан на Python 3.10+. Для установки и сборки рекомендуется Python 3.12.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python audio_cleaner.py --download-model --model-dir models

# Сохранить рядом с исходником как original_очищено.mp3
python audio_cleaner.py "original.m4a"

# Указать имя результата или выбрать быстрый режим
python audio_cleaner.py "original.m4a" "clean.mp3"
python audio_cleaner.py "original.m4a" "clean.aac"
python audio_cleaner.py "original.m4a" "fast.mp3" --engine fast --strength 60

python -m unittest discover -s tests -v
```

Без аргументов открывается графический интерфейс (нужен Tkinter). В CLI путь результата необязателен; по умолчанию создаётся `имя_очищено.mp3`. CLI заменяет существующий результат без запроса. Совпадение путей входа и выхода запрещено.

Параметры: `--strength 0..100`, `--no-enhance`, `--keep-pauses`, `--engine neural|fast`, `--model-dir PATH`, `--download-model`.

### Обработка звука

Нейросетевая модель **DPDFNet** с выходом 48 кГц запускается через **sherpa-onnx**. Очень тихая запись предварительно приводится к рабочему уровню модели; после очистки исходный уровень восстанавливается. Затем применяются срез низкочастотного гула, опциональное подавление фона в паузах и обработка голоса.

Громкость измеряется отдельно, затем применяется постоянное усиление с целью −16 LUFS и запасом по пикам −1,5 dBTP до кодирования MP3. Усиление ограничено 40 дБ; при нехватке запаса по пикам результат может быть тише цели. MP3-кодирование может немного изменить пики. При 0% шумоподавление и очистка пауз отключены, срез гула остаётся. Отключение усиления также отключает эквалайзер, компрессию и нормализацию.

### Модель и проверки

Модель хранится в `%LOCALAPPDATA%\AudioCleaner\models` (на Linux/macOS — `~/.cache/AudioCleaner/models`). Приоритет расположений: `--model-dir` → `AUDIO_CLEANER_MODELS` → папка `models` рядом с исходниками или внутри EXE → пользовательский кеш. Перед использованием проверяется SHA-256. Повторная установка заменяет повреждённую модель после проверки загрузки.

FFmpeg поставляется в пакете imageio-ffmpeg; при отсутствии пакета используется системный FFmpeg. Тесты проверяют сохранение голоса относительно чистого эталона, остаточный шум, длительность, форматы, отмену и защиту существующих файлов.
